### *1.* Algoritmo

|  Definición | Se refiere a un conjunto finito de pasos, los cuales son lógicos, precisos y ordenados; estos pasos nos permiten llevar a cabo una tarea.  |
|  --- |  --- |
|  Ejemplo |Un ejemplo sencillo es una receta de cocina. Esto se debe a que tiene un estado inicial en el cual encontramos los ingredientes, luego las instrucciones ordenadas y el estado final, el cual es el plato ya listo.|
---
### *2.* Programa

|  Definición | Se refiere a un plan estructurado el cual organiza y define el contenido de una serie de actividades. También se puede definir como el conjunto de instrucciones para que un dispositivo pueda ejecutar una secuencia específica de instrucciones. |
|  --- |  --- |
|  Ejemplo |Un programa de navegación web, como Google Chrome o Mozilla Firefox, le permite al usuario acceder a diferentes sitios web, leer y enviar correos.|
---
### *3.* Código fuente (Source code)

|  Definición |Se refiere al conjunto de instrucciones y declaraciones escritas en un lenguaje de programación, las cuales sirven para indicar a la computadora qué acciones va a realizar.  |
|  --- |  --- |
|  Ejemplo |Se podría tomar el ejemplo de la receta, donde el código fuente serán los pasos que se deben seguir para obtener una buena comida. |
---
### *4.* .Lenguaje de Programación 

|  Definición | Es un modelo sistemático de comunicación que permite a los seres humanos, mayormente a los programadores, dar instrucciones precisas y claras a una máquina. |
|  --- |  --- |
|  Ejemplo |Un ejemplo de un lenguaje de programación es Python, el cual se conoce como uno de los lenguajes más versátiles en la actualidad.|
---
### *5.* Sintaxis

|  Definición | La sintaxis se refiere a las normas o reglas que controlan la estructura de los símbolos, las palabras y la puntuación que se encuentran en los lenguajes de programación  |
|  --- |  --- |
|  Ejemplo |Por ejemplo, $a=3, donde a la variable $a se le asigna el valor 3, un string. Igualmente, para las condiciones se requieren los siguientes signos para poder evaluarse como verdadero o falso: <, >, y ==.  |
---
### *6.* Variable

|  Definición | Se le conoce como un contenedor el cual almacena los datos de un programa. Las variables se caracterizan por tener un nombre y una categoría asociada, lo cual permite que el programa ingrese a los datos de almacenamiento y los manipule. |
|  --- |  --- |
|  Ejemplo | -my $nombrecomp = “Prueba escrita”; – print “Ejemplo visto, $nombrecomp”; En este ejemplo se declara la variable llamada nombrecomp usando la palabra clave my.  |
---
### *7.* Constante

|  Definición | La constante, también llamada literal, se refiere al valor fijo que un programa no puede modificar de ninguna manera. |
|  --- |  --- |
|  Ejemplo | Un ejemplo es cuando dentro de un código se usa pi (3.14), el cual se puede declarar como constante ya que su valor no va a cambiar.  |
---
### *8.* Tipo de dato

|  Definición | Se refiere a una restricción o clasificación que se establece sobre los datos; esto ayuda a saber cómo se interpretan, manipulan y almacenan dentro de la memoria de una computadora. |
|  --- |  --- |
|  Ejemplo | Un ejemplo son los números enteros (int), los cuales corresponden a números sin decimales: 1, -5, 6, etc.   |
---
### *9.* Operador

|  Definición |  Se refiere al carácter que denota una acción o un proceso matemático, por lo que se caracteriza por ser un símbolo o una palabra clave que sirve para combinar las expresiones.  |
|  --- |  --- |
|  Ejemplo | Un operador puede ser algo tan simple como una suma o resta: Suma(a+b) o Resta(a-b)|
---
### *10.* Expresión

|  Definición | Es una combinación de valores, variables, constantes, operadores y funciones, los cuales se evalúan para obtener un producto. Es decir, son la manera en que se construyen los bloques de código.  |
|  --- |  --- |
|  Ejemplo |Un ejemplo es donde usemos una edad cualquiera y se le sume 5, Edad+5, siendo así edad la expresión y 5 otra literal, y el + un operador que las junta y crea una expresión más compleja. |
---
### *11.* Condicional

|  Definición |  Se refiere al control que permite tomar una decisión dentro del flujo en un programa. |
|  --- |  --- |
|  Ejemplo |Una condicional muy común es if, por ejemplo, if edad <= 18, donde se decide si alguien es menor de edad.  |
---
### *12.* Bucle (Loops) 

|  Definición |  El bucle, o mejor conocido como loop, se refiere a una secuencia de instrucciones que se repite hasta que se cumpla una condición en específico.  |
|  --- |  --- |
|  Ejemplo |Por ejemplo, cuando se usa el bucle for, el cual se usa cuando quieres repetir un bloque de código, sobre todo en listas o para ejecutar tareas.  |
---
### *13.* Función (Function) 

|  Definición | La función es el bloque donde se realiza una tarea específica y que se puede llamar cuantas veces se necesite dentro de un programa. |
|  --- |  --- |
|  Ejemplo | Por ejemplo, la función suma: ENTERO suma (ENTERO, numUno, ENTERO numDos)  |
---
### *14.* Parámetro (Parameter) 

|  Definición | Se puede decir que actúa como dato de entrada, ya que permite al procedimiento adaptarse y operar con los valores recibidos |
|  --- |  --- |
|  Ejemplo | Ejemplo en Python: def saludar(nombre, mensaje="Hola"): print(mensaje, nombre)|
---
### *15.* Argumento

|  Definición | Se refiere al valor que se entrega a una función al llamarla y que la función procesa para cumplir una tarea específica. |
|  --- |  --- |
|  Ejemplo | Por ejemplo, en sumar(a, b), a y b son parámetros; en sumar(5, 3), 5 y 3 son argumentos. |
---
### *16.* Retorno (Return) 

|  Definición | Se refiere a la declaración dentro de una función en la cual se termina el proceso y vuelve al código que la llamó.   |
|  --- |  --- |
|  Ejemplo | Por ejemplo, cuando hay una condición donde dice que si es mayor que 5 se acaba la operación; de lo contrario, el valor vuelve al inicio y se le suma uno hasta que se cumpla esta condición|
---
### *17.* Arreglo (Array) 

|  Definición |   El arreglo, también llamado array, se refiere a la estructura de datos la cual almacena muchos valores en una lista ordenada.  |
|  --- |  --- |
|  Ejemplo |Ejemplo: el arreglo de números enteros, int[] números = {1, 2, 3, 4, 5}, dentro de este arreglo se guardaba una serie de números enteros para su procesamiento.  |
---
### *18.* Objeto (Object) 

|  Definición |   Se refiere a la instancia que se crea a partir de una clase que contiene datos y acciones definidos dentro de esa clase. |
|  --- |  --- |
|  Ejemplo | Objeto “cafetera” Sus propiedades: marca, capacidad, tipo de café. Métodos: preparar café, limpiar, encender.|
---
### *19.* Método (Method)  

|  Definición | Se refiere a la función relacionada con una clase o un objeto que define un comportamiento en específico. |
|  --- |  --- |
|  Ejemplo | Cuando se pone a calentar el café, se usa el botón, el cual se puede considerar como el que activa este método. |
---
### *20.* Evento

|  Definición |  Es la acción o suceso que ocurre dentro de un programa. Estos provocan respuestas predeterminadas.  |
|  --- |  --- |
|  Ejemplo | Por ejemplo, cuando tocamos un timbre de una casa, el timbre sería el evento y el sonido la respuesta. |
---
### *21.* Compilador

|  Definición |  Es un programa que se encarga de traducir el código escrito por el programador en un lenguaje de alto nivel a lenguaje de máquina, así la computadora lo puede ejecutar.  |
|  --- |  --- |
|  Ejemplo | Por ejemplo, cuando se escribe un programa en C++ o JavaScript, el compilador se encarga de traducir el código para que la máquina lo pueda leer y ejecutar. |
---
### *22.* Intérprete

|  Definición |  Es un programa igual que el compilador, pero este ejecuta el código fuente escrito en un lenguaje de alto nivel, traduciéndolo y corriendo el código línea por línea en tiempo real sin necesidad de compilar todo el programa antes. |
|  --- |  --- |
|  Ejemplo | Por ejemplo, Python es un intérprete que lee cada línea del código y la ejecuta inmediatamente, mostrando a su vez los resultados.  |
---
### *23.*  Depurador (Debugger) 

|  Definición |  Se trata de un programa que se encarga de ayudar a encontrar y corregir errores en otro software mientras se está ejecutando, lo que permite analizar el código y su interacción con el sistema sin necesidad de detenerlo.   |
|  --- |  --- |
|  Ejemplo | Cuando se desarrolla en JavaScript, se puede usar un depurador integrado, ya sea Chrome o Firefox, para revisar línea por línea el código hecho , así detectar fallos y probar soluciones en tiempo real.  |
---
### *24.* IDE (Entorno de Desarrollo Integrado) 

|  Definición |  Es un software que reúne dentro de una sola interfaz herramientas como editor de código, compilador e intérprete, así como el depurador y otras utilidades, facilitando el desarrollo de software.|
|  --- |  --- |
|  Ejemplo | Un gran ejemplo de esto es Visual Studio Code es una IDE que permite escribir el código, depurarlo y ejecutarlo desde la misma aplicación.  |
---
### *25.* Editor de código

|  Definición |  Es una herramienta que permite escribir y modificar un código fuente de manera organizada, ofreciendo funciones que mejoran la legibilidad y eficiencia del trabajo del programador.  |
|  --- |  --- |
|  Ejemplo | Un ejemplo de esto es Visual Studio Code, ya que, como he mencionado antes, este es un editor de código que te sugiere cómo completar tu código y ayuda a detectar los errores.  |
---
### *26.* Biblioteca o libreria (Library)

|  Definición |  Es una colección de funciones, métodos o clases que ya están creadas por otros programadores, así pueden reutilizarlos en distintos proyectos, evitando escribir el mismo código varias veces y aumentar la eficiencia |
|  --- |  --- |
|  Ejemplo | Un ejemplo es la biblioteca NumPy. Esta proviene de Python y ofrece funciones matemáticas y de álgebra lineal listas para usar, lo que permite trabajar con matrices y cálculos complejos.  |
---
### *27.* Framework

|  Definición |  Es un conjunto de herramientas, bibliotecas y reglas que ofrecen una estructura base para poder crear aplicaciones de forma más rápida y organizada.  |
|  --- |  --- |
|  Ejemplo |  Un ejemplo de esto es Django, un framework de Python que facilita el desarrollo de los sitios web al incluir funciones ya listas para manejar las bases de datos, la seguridad y el diseño.  |
---
### *28.*  API (Application Programming Interface) 

|  Definición |  Es un conjunto de reglas y protocolos que permiten que dos programas distintos se comuniquen y compartan funciones o datos.  |
|  --- |  --- |
|  Ejemplo |  Un ejemplo de esto es cuando una aplicación de viajes muestra un mapa con rutas; está usando la API de Google Maps para obtener la información y mostrarla dentro de su propia app.   |
---
### *29.*  Repositorio (Repository)

|  Definición |  Se trata de un almacén donde se guardan y gestionan los archivos y el código de un proyecto, normalmente usando sistemas de control de versiones como Git para registrar los cambios y facilitar el trabajo en equipo. |
|  --- |  --- |
|  Ejemplo |  Un ejemplo muy claro de esto es GitHub, este sitio es donde los desarrolladores guardan sus proyectos en repositorios para colaborar, actualizar el código y mantener un historial de versiones.  |
---
### *30.*  Control de versiones (version control)

|  Definición |  Es un sistema que registra los movimientos y cambios realizados en un código de un proyecto, permitiendo trabajar en equipo.  |
|  --- |  --- |
|  Ejemplo |  Un ejemplo es Git, el cual es un sistema de control de versiones que guarda y gestiona cada cambio del código, facilitando la colaboración entre varios desarrolladores.  |
---
### *31.* Git

|  Definición |  Se trata de un sistema de versiones distribuido que registra y administra los cambios en los archivos de un proyecto y ayuda a mantener un historial seguro y eficiente de las modificaciones.  |
|  --- |  --- |
|  Ejemplo |  Un ejemplo de esto es cuando varios desarrolladores trabajan en un mismo proyecto dentro de GitHub. Git guarda cada cambio en el código y especifica quién y cuándo lo modificó.  |
---
### *32.* GitHub

|  Definición |  Es una plataforma en línea que permite que los desarrolladores guarden sus proyectos en repositorios dentro de Git.  |
|  --- |  --- |
|  Ejemplo |  Un ejemplo de esto es cuando un equipo de desarrollo puede subir su proyecto a Github para trabajar en distintas partes del código desde diferentes lugares y usar Git para coordinar cambios, revisar las versiones y mejorar el código. |
---
### *33.* Rama (Branch)

|  Definición |  Se trata de una línea paralela de desarrollo dentro de un proyecto que permite trabajar en nuevas funciones o corregir errores sin modificar la versión principal del código, normalmente se le denomina main.   |
|  --- |  --- |
|  Ejemplo |  Un ejemplo de esto es que en Git, puedes crear una rama llamada nueva-funcionalidad para probar cambios; cuando todo funciona bien, se fusiona con la rama principal (main).  |
---
### *34* Commit

|  Definición |  Se trata de una acción en un sistema de control de versiones como Git que guarda un estado específico del código, registrando los cambios realizados para mantener un historial del proyecto.   |
|  --- |  --- |
|  Ejemplo |  Por ejemplo, cuando terminas de modificar una parte del código y ejecutas el comando git commit -m "corrige error de inicio", Git guarda esa versión del proyecto con una descripción del cambio.   |
---
### *35.*  Merge (Fusión)

|  Definición | Se trata de una operación en un sistema de control de versiones que combina dos ramas o versiones diferentes de un proyecto en una sola, integrando así los cambios que hubo en ambas.  |
|  --- |  --- |
|  Ejemplo |  Por ejemplo, en Git, si trabajas en una rama llamada formula1 y quieres unirla con la rama principal (main), realizas un merge para que el código de ambas quede integrado 
en un mismo historial.   |
---
### *36.*  Callback (función de retorno) 

|  Definición |  Se trata de una función que se pasa como argumento a otra función y se ejecuta después de que esta termina su tarea, muy usada en programación asíncrona para manejar resultados o eventos posteriores.   |
|  --- |  --- |
|  Ejemplo |  Por ejemplo, en JavaScript, cuando se usa setTimeout(() => { console.log("Listo"); }, 2000);, la función dentro de los paréntesis es un callback que se ejecuta después de 2 segundos, una vez que la función principal ha terminado.   |
---
### *37.* Programación síncrona 

|  Definición |  Se trata de un tipo de lenguaje diseñado para programar sistemas reactivos, es decir, aquellos que deben responder a estímulos del entorno en tiempos estrictos.  |
|  --- |  --- |
|  Ejemplo |  Un ejemplo de esto son lenguajes como Esterel, Lustre o SIGNAL, creados en los años 80, que permiten especificar que una señal ocurra exactamente en sincronía con otra.  |
---
### *38.*  Programación asíncrona

|  Definición |  Se trata de un lenguaje que permite que ciertas operaciones se ejecuten en  segundo plano sin bloquear el flujo principal del programa. Es especialmente útil en tareas que dependen de entrada/salida (I/O), como llamadas a APIs, lectura de archivos o consultas a bases de datos.  |
|  --- |  --- |
|  Ejemplo | Por ejemplo, en JavaScript, al usar fetch() para obtener datos de una API, el programa puede seguir ejecutando otras instrucciones mientras espera la respuesta.  |
---
### *39.*  JavaScript

|  Definición | Es un lenguaje de programación interpretado que se ejecuta directamente en el navegador y permite crear experiencias interactivas en páginas web. También puede utilizarse en servidores mediante tecnologías como Node.js, lo que lo convierte en un lenguaje versátil tanto para el desarrollo frontend como backend.   |
|  --- |  --- |
|  Ejemplo | Por ejemplo, cuando haces clic en un botón y aparece una animación o se actualiza una parte de la página sin recargarla, eso se logra con código JavaScript.  |
---
### *40.*  TypeScript

|  Definición |  Es un lenguaje de programación de código abierto creado por Microsoft. Se define como un superconjunto tipado de JavaScript, lo que significa que añade características como tipos estáticos y herramientas de desarrollo avanzadas, manteniendo la compatibilidad con todo el código JavaScript existente. .  |
|  --- |  --- |
|  Ejemplo | Por ejemplo, en un proyecto web, puedes escribir funciones en TypeScript con tipos explícitos para evitar errores, y luego el código se compila a JavaScript para ejecutarse en el navegador o en Node.js.    |
